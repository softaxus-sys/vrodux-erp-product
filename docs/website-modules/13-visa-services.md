# Visa Services

**Headline:** Run a UAE visa consultancy: every case, document and deadline in one place.
**Tagline:** Case management with checklists, renewals, invoicing and government submission tracking.

## Features
- **Cases** — wizard to create a case (visa type, client, applicants with dependants); board and list; SLA due dates and overdue chips; status machine (draft → documents pending → documents complete → submitted → in review → approved → issued → closed, with rework/RFI loops); only legal next steps are offered.
- **Document checklist** per applicant copied from the visa type; case advances when the last document is verified.
- **Visa types** — a UAE catalogue (employment new/renewal/cancellation, family, visit, golden, freelance, student) copied per workspace; edit fees, processing days and required documents.
- **Renewals** — passport, document and **issued-visa expiry** tracking (30/60/90/180-day horizons).
- **Dashboard** — totals, overdue, expiring, by status/type, revenue, PRO workload.
- **Billing** — generate a draft invoice in Finance from a case (service fee + government fee); link back on the case. Link cases to CRM accounts; create a case from a CRM lead.
- **Submissions** — record government transactions per case (manual channel works today); channel settings page with encrypted credentials.
- Permissions on cases; AI assistant tools for cases.

## Do not claim yet
- **No live connection to government systems.** UAE PASS is a beta placeholder; GDRFA/ICP/MOHRE adapters are "coming soon" (manual recording only).
- Client self-service portal.
