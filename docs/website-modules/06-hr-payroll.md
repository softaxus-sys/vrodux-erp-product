# HR, Attendance, Leave & Payroll

**Headline:** Run people operations — from hiring to a bank-ready salary file.
**Tagline:** Employees, attendance with office hours, leave entitlements, payroll with Finance approval, UAE WPS, and employee self-service.

## Features
**Employees** — directory, create/edit, photo, designations (add your own), personal and compliance details (Emirates ID, passport, visa expiry), bank/IBAN, labour card number, bank routing code; profile print.

**Attendance**
- Mark attendance (bulk shortcuts), **office timings** (start/end, grace minutes, working days, time zone), on-time vs late (minutes recorded per day), times stored in local time.

**Leave**
- Request/approve/reject/cancel; **leave policies** (UAE-baseline defaults you can edit); balances = entitlement − approved − pending, per employee and all-staff.

**Payroll**
- Create runs with per-employee allowances/deductions and bulk adjusters; status chain **draft → processed → Finance-approved → paid**; reject with reason, edit and reopen.
- **Finance approves before money moves**: Finance can edit slips, approve or reject; approval can post an accrual journal entry.
- Payslip email tracking; payslip PDF for employees.
- **WPS salary file (SIF)**: employer ID and agent routing code in settings, labour card and IBAN per employee; IBANs validated (mod-97); shows who is excluded and why; filename follows the standard.

**Recruitment & performance** — job postings, careers portal (public), reviews.

**Employee self-service ("My HR")** — own profile, check in/out, attendance history, leave balances and requests, payslips (PDF). A self-service employee cannot see the staff directory or any salaries.

**Logins** — create an employee's login from their record (email invite or temporary password), link an existing login, with seat-limit checks.

## Works with
Finance (payroll approval and posting), notifications (leave requests, payroll approvals), mobile app (self-service), AI assistant.

## Access control
Permissions for employees (incl. create-login), attendance, leaves, payroll (approve/print), performance, recruitment, and separate self-service keys.

## Do not claim yet
- WPS: verify the file against your bank/exchange house template before the first live submission; Vrodux does not submit to the bank.
- GPS on check-in; payslip PDF is browser print-to-PDF.
- Per-employee shift schedules (one workspace schedule today).
- Employee documents store (compliance dates are tracked, files are not stored).
