# Project Management

**Headline:** Boards, sprints and issues — with access that follows the team.
**Tagline:** Kanban and backlog for any team.

## Features
- **Projects** with a team (owner / member / viewer); users only see projects they belong to (admins see all). The only owner can't be removed.
- **Kanban board** with drag-and-drop columns (manage columns), **backlog**, **sprints** (start/complete), **issues** list, labels, comments, issue drawer.
- Assigning an issue notifies the assignee.
- Permissions per area (projects, boards, labels, sprints, issues) and enforcement on both server and UI (drag-drop disabled without edit rights).
- AI assistant can list and create issues (with confirmation).

## Do not claim yet
- Time tracking, Gantt charts, project billing, automations.
- Sprint/label/column/comment visibility checks per project are partly applied (project list and issue detail are enforced).
